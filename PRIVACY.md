# Privacy

Minecraft Server Hub is designed as a self-hosted application.

The operator controls the host computer, Minecraft servers, networking, logs, backups, and integration credentials.

The public project website does not need to collect account credentials, Minecraft world data, server authentication information, or CurseForge API keys.

GitHub Pages itself is hosted by GitHub and is subject to GitHub's own platform privacy and logging practices.

## CurseForge

When CurseForge integration is used, the application may send the project/file identifiers required to resolve a user-supplied CurseForge manifest to the CurseForge API.

Minecraft Server Hub is not intended to publish the user's API key or re-host downloaded CurseForge content.
