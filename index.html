Server operations without the busywork.

Minecraft Server Hub consolidates the repetitive operational work required to run multiple Minecraft servers, especially modded environments.

Lifecycle & health

Start, stop, restart, monitor, recover from crashes, and track server readiness from one interface.

Server-pack deployment

Analyze pack metadata, loader requirements, Java, EULA, RAM, ports, and first-start health checks.

Player connection endpoints

Generate copy-ready Radmin VPN, ZeroTier, LAN, or public addresses with each server's real port.

Mod-aware control

Use mod-specific command shortcuts, macros, and safe configuration shortcuts for supported formats.

Backups & recovery

Keep server backups, update rollback points, crash reports, logs, watchdog retries, and crash-loop protection.

MCSManager integration

Register and operate server instances while keeping management credentials on the self-hosted Hub.

CurseForge integration with distribution controls respected.

For user-provided CurseForge manifest-based server packs, Minecraft Server Hub uses the official API to resolve project/file metadata and retrieve only files available for third-party distribution.

  • No public file mirror
  • No re-hosting of CurseForge artifacts
  • No bypass of project distribution settings
  • No redistribution of CurseForge API keys
  • API credentials remain server-side

Private operational data stays private.

The public project profile contains no server credentials, API keys, authentication state, world files, backups, or private runtime configuration.

  • CurseForge and MCSManager keys are treated as server-side secrets
  • Private Hub configuration is excluded from the public repository
  • Minecraft world and backup data are not part of this site
  • The repository includes a defensive .gitignore for common private paths
